# Baraboo Lions Brand Preview

This repository contains the design system and style guide for websites and digital projects maintained by the Baraboo Lions Club and Foundation.

The purpose of this repository is to establish a consistent visual identity, layout, and user experience across all Baraboo Lions websites, events, and community initiatives.

## Design Principles

- Community-focused
- Trustworthy
- Easy to maintain
- Mobile friendly
- Accessible
- Consistent across programs

## Programs

Examples include:

- Strides Against Diabetes
- Scholarships
- Vision Programs
- Community Service Projects

## Mission

100% of public funds raised are reinvested in the community.
